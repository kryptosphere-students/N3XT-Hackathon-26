# Standards de code stricts

Tout code livré doit respecter :
- Tests systématiques (unitaires + intégration sur logique métier).
- **Conventional Commits**.
- Lint **zéro warning**.
- Doc API publiques (signature + intent + contrat + exemple).
- Sécurité OWASP Top 10 + Web3 (Slither, Foundry tests, Checks-Effects-Interactions).
- Naming explicite. Pas de magic numbers — constantes nommées.
