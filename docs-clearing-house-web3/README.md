# Clearing House web3

Dossier de travail pour un service de clearing B2B sur parts de fonds, proposé à des dépositaires centraux (CSD) sous forme de logiciel licencié, avec signatures Ledger et agents.

Ce dossier contient de la documentation uniquement. Aucun code de ce projet n'est présent à ce stade. Il est distinct du POC BTC copilot du hackathon, dont le périmètre est décrit dans `docs/`.

## Contenu

- `cadrage.md` : hypothèses retenues (éditeur de logiciel, préfinancement sans CCP, Ledger pour la signature), architecture, modèle de licence et revenus, hypothèses économiques à valider, concurrents, questions ouvertes.
- `spec-poc.md` : spec du POC pour le hackathon (cas d'usage, parcours de démo, stack technique figée, replis, planning, questions restantes).
